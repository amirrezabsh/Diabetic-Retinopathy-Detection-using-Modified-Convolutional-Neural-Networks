# Notebooks

This directory contains the original thesis notebook.

## Files

- `BscProject.ipynb`: end-to-end diabetic retinopathy classification workflow, including image loading, preprocessing, CNN/transfer-learning model setup, training, and evaluation plots.

## Usage Notes

Run the notebook from the repository root so relative paths can be adjusted consistently.

For a clean rerun:

1. Create and activate a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Place the dataset according to `docs/dataset.md`.
4. Execute the notebook cells in order.
